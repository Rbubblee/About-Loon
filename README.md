个人使用的一些网络工具

## Loon 插件

- `Plugin/Zeekr_remove_ads.lpx`：极氪 App 去广告与页面精简，支持社区整页、商城整页、首页营销位、弹窗、Banner 和营销消息独立开关。
- `Plugin/充电桩修改.lpx`：极氪 App 家充桩页面接入银河家充桩数据。
- `Plugin/Midea_remove_ads.lpx`：美的美居 App 去广告。
- `Plugin/ChangeUA.plugin`：网页 User-Agent 调整。
- `Plugin/EmbyPremiere解锁.plugin`：Emby 配置增强。
- `Plugin/一汽大众APP.plugin`：一汽大众 App 去广告。
